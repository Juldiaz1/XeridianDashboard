# Xeridian Dashboard

An AI-powered fitness tracking dashboard built with React Native and Expo. This app focuses on camera-based form tracking, AI coaching insights, and weight/performance correlation.

## Features
- Premium Dark UI: A modern, high-contrast aesthetic inspired by top-tier fitness apps.
- AI Form Analysis: Tracks Total Reps, Correct Form, and Incorrect Form with interactive breakdowns.
- Performance & Weight Correlation: Interactive line charts showing how weight loss correlates with rep endurance.
- Interactive Insights: Tap on cards to view detailed modal insights, weekly improvements, and AI coach tips.
- Custom Navigation: Floating bottom navigation bar for a seamless app experience.

## Tech Stack
- React Native & Expo
- TypeScript
- React Navigation (for routing)
- Expo Vector Icons (Ionicons)

## Quick Start (2 Steps)

1. Install dependencies:
   npm install

2. Start the Expo server:
   npx expo start
   (If you want to test in the browser, use: npx expo start --web --port 8082)

## Full Setup Instructions

1. Fork or Clone this repo:
   git clone https://github.com/Juldiaz1/XeridianDashboard.git
   cd XeridianDashboard

2. Install dependencies:
   npm install

3. Start the app:
   npx expo start

4. Open the app:
   - On iOS: Scan the QR code from the terminal using your iPhone's Camera app.
   - On Android: Scan the QR code using the Expo Go app.
   - On Web: Press w in the terminal or run npx expo start --web --port 8082.
